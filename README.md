
# 🍴 Zomato Delivery Analytics

## 📌 Project Overview

This project is a **descriptive data analytics project** based on three months of Zomato delivery data obtained from Kaggle.

The project focuses on analyzing **order patterns, delivery performance, traffic conditions, city-wise demand, weekdays, festivals, and order categories**.

The raw data was cleaned and prepared using **Python and Excel**, followed by analysis and interactive dashboard development using **Microsoft Power BI**.

The project demonstrates an end-to-end data analytics workflow:

**Raw Data → Data Cleaning → Data Preparation → Descriptive Analysis → Power BI Visualization → Insights**

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze monthly order trends
* Understand different order categories and types
* Analyze average delivery time
* Study delivery patterns across different hours
* Examine the impact of road traffic on delivery time
* Compare delivery performance across different cities
* Analyze weekday-wise order demand
* Compare festival and non-festival orders
* Identify patterns in customer ordering behavior

## 🔄 Project Workflow

### 1. Data Collection

The dataset containing Zomato delivery records was obtained from **Kaggle** and covers a period of three months.

### 2. Data Cleaning

The raw dataset was cleaned and prepared using **Python and Excel**.

The cleaning process included:

* Handling missing values
* Checking and correcting data types
* Cleaning date and time-related fields
* Identifying inconsistent values
* Standardizing categorical data
* Checking the dataset for duplicates and errors
* Preparing the final dataset for analysis

### 3. Descriptive Analysis

The cleaned data was analyzed to understand patterns in:

* Orders
* Delivery time
* Traffic conditions
* Cities
* Order categories
* Weekdays
* Festivals
* Ordered hours

### 4. Power BI Dashboard

The cleaned dataset was imported into Power BI to create **interactive dashboards** with KPIs, charts, slicers and filters.

# 💡 Key Insights

The analysis provides a descriptive view of Zomato's delivery and ordering patterns, including:

* Monthly order demand varies across the three-month period it normally distributed data.
* Different road traffic conditions are associated with differences in delivery performance.
* Ordering demand changes throughout the week, with noticeable variations between weekdays.
* Delivery time varies across different hours of the day.
* Festival orders represent a relatively small proportion of total orders in the analyzed dataset.
* Order distribution can be compared across different city categories.
* Different order categories contribute to the overall order volume.

> **Note:** These findings are descriptive and are based only on the three-month dataset analyzed in this project. They should not be interpreted as causal relationships or representative of Zomato's overall business performance.
